# WinSCP — Free Offline Installer

![Category](https://img.shields.io/badge/FTP/SFTP_Client-blue?style=flat-square)

## About

WinSCP is a free, open-source Windows file transfer client for SFTP, FTP, WebDAV, Amazon S3, and SCP. Features a dual-pane file manager, drag-and-drop between local and remote, synchronization, background transfers, and extensive scripting and automation capabilities via .NET assembly. WinSCP is the standard Windows SFTP client for secure server file management.

## Common Problems & Limitations

- **Windows Only** — No macOS or Linux version
- **Interface Options** — Commander and Explorer interface modes available but each has UX quirks
- **Complexity** — Automation scripting capabilities make configuration options extensive
- **Performance** — Very large directory listings can be slow to load
